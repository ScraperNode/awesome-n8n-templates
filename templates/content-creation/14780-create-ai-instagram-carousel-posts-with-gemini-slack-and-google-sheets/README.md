## Description

This workflow automatically generates a 6-slide Instagram carousel about tech topics(you can edit the prompt how you like to make it for best for your usecase)  every day at noon(you can set whatever time you want or manually use it), creates images for each slide using AI, uploads them to Slack with captions, and logs the topic to Google Sheets to avoid repeating subjects.

## 🔗 Nodes Used

Google Sheets, Slack, Schedule Trigger, Google Gemini

## 📥 Import

Download [`workflow.json`](workflow.json) and import into n8n:
**Workflow menu → Import from File**
