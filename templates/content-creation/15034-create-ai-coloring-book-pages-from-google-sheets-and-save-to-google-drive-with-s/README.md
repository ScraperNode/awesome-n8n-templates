# 🎬 Create AI coloring book pages from Google Sheets and save to Google Drive with Stable Diffusion

> ⚡ **285 views** · 🎬 [Content Creation & Video](../)

## Description

This workflow automatically generates printable coloring pages from themes stored in Google Sheets.

It reads configuration data such as theme, style, and keywords, creates prompts, generates multiple image variations using AI, and saves the results to Google Drive.

Finally, it logs metadata to Google Sheets for easy tracking and management.

## 🔗 Nodes Used

Google Sheets, HTTP Request, Google Drive, Schedule Trigger

## 📥 Import

Download [`workflow.json`](workflow.json) and import into n8n:
**Workflow menu → Import from File**
