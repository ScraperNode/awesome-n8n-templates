# ⚒️ Generate GTIN-14 test values for product feeds with Ecomwith

> ⚡ **1 views** · ⚒️ [Engineering](../)

## Description

## Quick overview
Generate format-valid GTIN-14 test values and map them to SKU prefixes for ecommerce feed QA. Learn more: https://ecomwith.com/tools/gtin

## How it works
1. Receives quantity and SKU prefix from the GTIN Form.
2. Logs the raw form payload to the n8n run-log Data Table for traceability.
3. Bounds quantity and trims the SKU prefix before creating an idempotent request.
4. Calls the Ecomwith GTIN Generator and formats the returned GTIN-14 values.
5. Maps every generated value to its source SKU prefix for product-feed QA.
6. Returns quota and rate-limit metadata, or a structured error object with troubleshooting links.

## Setup
1. Create an Ecomwith API key with scope tools:gtin:generate at https://ecomwith.com/settings/apikeys.
2. Store it in an n8n HTTP Header Auth credential named Ecomwith API with header X-API-Key.
3. Confirm the credential is selected by the HTTP Request node and the n8n-creator-run-log Data Table exists.
4. Submit the generated form URL with a small quantity and keep the workflow inactive until the credential and smoke test are verified.

## Requirements
- An n8n HTTP Header Auth credential named Ecomwith API; scope tools:gtin:generate; access to the n8n-creator-run-log Data Table; quantity 1–100 and a SKU prefix for each test request.

## Customization
- Adjust the form fields, quantity bounds, SKU prefix convention, or result columns for a different product-feed QA process. Keep the format-validation boundary visible in the guide note.

## Additional info
Values generated by this workflow are for format QA and are not official GS1 assignments. Review https://ecomwith.com/tools/gtin before using the output.

## 🔗 Nodes Used

HTTP Request, n8n Form Trigger, Data table
