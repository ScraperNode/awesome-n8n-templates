# 📁 Export Mirakl offers as CSV and send by email with Gmail

> ⚡ **34 views** · 📁 [File Management](../)

## Description

Automate the export of your Mirakl offers in just a few minutes.

This workflow retrieves your offers through the API, generates a CSV file, and automatically sends it to you with an email.

Perfect for e-commerce merchants and marketplace managers who want to save time without manual effort.

## 🔗 Nodes Used

HTTP Request, Gmail, Schedule Trigger

## 📥 Import

Download [`workflow.json`](workflow.json) and import into n8n:
**Workflow menu → Import from File**
