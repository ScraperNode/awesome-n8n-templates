# 🔬 Qualify and approve live face-swap session requests with LiveFaceSwap forms

> ⚡ **0 views** · 🔬 [Document Extraction & Analysis](../)

## Description

Collect an authorized face-swap session request, protect image fetches, inspect both source and reference assets, branch by effect, and require a human approve/change/reject decision before a private test. Includes an executable credential-free sample and makes no claim of a public transformation API.

## 🔗 Nodes Used

HTTP Request, n8n Form Trigger, n8n Form

## 📥 Import

Download [`workflow.json`](workflow.json) and import into n8n:
**Workflow menu → Import from File**
